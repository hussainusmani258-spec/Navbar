# Responsive Navigation Bar

A modern, responsive header navigation bar built using semantic HTML5 and clean CSS3.

## 📌 Features
- **Logo & Branding:** Structured alignment for brand identity.
- **Dropdown Options:** Functional dropdown menus for navigation links.
- **Action Buttons:** Pre-styled call-to-action buttons for user login/signup.
- **Flexbox Layout:** Clean spacing and alignment using CSS Flexbox.

## 🛠️ Tech Stack
- **HTML5**
- **CSS3**
